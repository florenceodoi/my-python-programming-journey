## What I Learned

### 1. Introduction to Python

I learned that Python was created by Guido van Rossum and was designed to be readable and easy to understand.

Python is an open-source programming language and is widely used in different areas of computing.

### 2. Components of a Programming Language

I learned that a language has four important components:

- Alphabet
- Lexis
- Syntax
- Semantics

Alphabet refers to the symbols used by a language.

Lexis refers to the valid words of the language.

Syntax refers to the rules used to correctly arrange instructions.

Semantics refers to the meaning of the instructions.

### 3. Machine Language and High-Level Language

I learned that computers ultimately work with machine language consisting of binary values such as 0 and 1.

High-level languages such as Python make programming easier because their instructions are more understandable to humans.

### 4. Compilation and Interpretation

I learned the difference between compilation and interpretation.

Compilation translates source code before execution.

Interpretation processes and executes program instructions as the program runs.

Python uses an interpreter to execute Python programs.
